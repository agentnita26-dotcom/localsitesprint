# Local Site Sprint - one-page site

This folder contains a simple static one-page sales site.

## Files
- `index.html` - page structure and copy
- `styles.css` - styling only

## Quick custom edits
Open `index.html` and replace these placeholders first:
- `[YOUR EMAIL]`
- `[YOUR PHONE]`
- `[PRIMARY CTA LINK]`
- `[WHATSAPP LINK]`
- `[BOOKING LINK]`
- `[YOUR AREA / UK-WIDE / REMOTE]`
- `[PRIVACY POLICY LINK]`

## Best CTA link options
Use one primary path and repeat it everywhere:
- Calendly booking link
- WhatsApp direct link
- mailto link
- hosted enquiry form

Example:
- `https://calendly.com/yourname/quick-quote`
- `https://wa.me/447700900000`
- `mailto:hello@example.com`

## Quick launch
Because this is plain HTML/CSS, you can:
- open `index.html` directly in a browser
- upload the folder to basic hosting
- drop it into Netlify / Vercel / GitHub Pages if wanted later

## Fast customisation ideas
- Change `LS` in the brand circle near the top if you want different initials
- Swap the price text if the offer changes
- Replace the contact placeholder box with a real form embed
- Add real reviews in the trust sections later
- Split sections into separate pages only if needed

## Important note
This is intentionally simple. Good. Simple ships.
